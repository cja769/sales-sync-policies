# Sales Sync

Sales Sync is an internal bookkeeping integration for Third Coast Homebrew and Ultimate Pet Spa. It prepares summary journal entries from Lightspeed or MoeGo for the corresponding QuickBooks Online company.

Authorized operators manage sync runs through the private GitHub Actions workflow. During setup, the workflow previews journal entries. Review the source totals and account mappings before enabling posting.
