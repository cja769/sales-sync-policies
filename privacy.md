# Sales Sync Privacy Policy

Effective November 16, 2026

Jay Aisenbrey operates Sales Sync for internal bookkeeping. Sales Sync reads sales and payment records from authorized Lightspeed or MoeGo accounts and uses connected QuickBooks company and account information to prepare summary journal entries. When live posting is enabled, it sends those entries to the corresponding QuickBooks Online company.

GitHub Actions processes the data during sync runs. The workflow is configured to report counts and status without printing financial payloads to its run logs. The private repository is configured to retain workflow logs for 90 days. It stores rotated QuickBooks refresh tokens in encrypted form and keeps the encryption keys in GitHub Actions secrets. GitHub Pages logs visitor IP addresses for security when it serves these public policy pages.

For questions, access or deletion requests, or help disconnecting, email [aisenbreyjay@gmail.com](mailto:aisenbreyjay@gmail.com). Disconnecting in QuickBooks revokes future access. For cleanup of the stored connection, contact the operator to remove the active token and configuration. Encrypted copies can remain in private Git history after the authorization is revoked. Previously posted entries stay in QuickBooks and can be managed there by an authorized user.
